# To-Do List

Lista de tareas web hecha con HTML, CSS y JavaScript puro (sin dependencias). Las tareas se guardan en el navegador con `localStorage`, así que siguen ahí al recargar la página.

## Funciones

- Agregar tareas con el botón **+** o con la tecla Enter (máximo 100 caracteres).
- Marcar y desmarcar tareas como completadas.
- Eliminar una tarea con el botón **×**.
- Botón **Limpiar completadas** para borrar todas las tareas terminadas.
- Contador de tareas pendientes.
- Diseño adaptado a pantallas pequeñas.

## Cómo usarla

1. Clona o descarga el repositorio.
2. Abre `index.html` en tu navegador.

No hace falta servidor ni instalación. Las tareas quedan guardadas solo en ese navegador (clave `todo-list-2025` en `localStorage`).

## Archivos

| Archivo | Contenido |
|---|---|
| `index.html` | Estructura de la página |
| `style.css` | Estilos |
| `app.js` | Lógica de tareas, guardado y contador |
